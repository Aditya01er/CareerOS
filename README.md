# CareerOS

Developer Career Intelligence — public profile analysis, resume analysis, live India job discovery, voice career coach, and WhatsApp alert integration.

## Architecture

The frontend is static. Backend endpoints currently use the Hatchable runtime SDK and are kept here as the source snapshot while the Vercel runtime migration is completed.

## Data policy

CareerOS is designed to show verified public-source data only and does not fabricate profile metrics, jobs, skills, or private activity.
